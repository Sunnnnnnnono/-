# 하중 분석 GUI

CSV의 시간-하중 데이터를 읽어 단면적과 응력을 계산하고, 시간-응력 그래프와 최대 응력 및 해당 시간을 표시하는 Tkinter 프로그램입니다.

## 실행 방법

프로젝트 루트(`코딩과응용`)에서 PowerShell을 열고 실행합니다.

```powershell
.\.venv\Scripts\python.exe ".\코딩과응용 5주차\load_analyzer_Gui.py"
```

필요한 Python 패키지는 `numpy`, `pandas`, `matplotlib`입니다. 가상환경에 설치되어 있지 않다면 프로젝트 루트에서 다음 명령으로 설치합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install numpy pandas matplotlib
```

## CSV 형식

CSV 첫 행에 아래 열 이름이 정확히 있어야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s |
| `force_N` | 하중 | N |

예시:

```csv
time_s,force_N
0,0
1,100
2,250
```

각 열의 값은 숫자여야 합니다. 빈 값, 숫자가 아닌 값, `NaN` 또는 무한대가 포함된 행은 유효 행에서 제외합니다. 응력은 `하중(N) / 단면적(mm²)`로 계산하며, 이 단위 조합의 결과는 MPa입니다.

## 단면과 치수

치수 단위는 모두 mm, 계산 단면적 단위는 mm²입니다. GUI는 선택한 단면에 필요한 치수 입력칸만 표시합니다.

| 단면 종류 | 입력 치수 (mm) | 단면적 계산식 | 유효 조건 |
| --- | --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `A = b × h` | `b > 0`, `h > 0` |
| 원형봉 | 직경 `d` | `A = πd² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 두께 `t` | `A = π[D² − (D − 2t)²] / 4` | `D > 0`, `t > 0`, `2t < D` |
| 사각형관 | 외측 폭 `B`, 외측 높이 `H`, 두께 `t` | `A = BH − (B − 2t)(H − 2t)` | `B > 0`, `H > 0`, `t > 0`, `2t < min(B, H)` |
| H형강 | 전체 높이 `H`, 플랜지 폭 `B`, 웨브 두께 `tw`, 플랜지 두께 `tf` | `A = 2Btf + (H − 2tf)tw` | 모든 치수 `> 0`, `2tf < H`, `tw ≤ B` |

## 이상화 단면 가정

- 각 형상은 입력한 치수로 표현되는 이상적인 단면으로 계산합니다. 모서리 라운드, 필릿, 모따기, 용접부, 제조 공차 및 국부 형상은 고려하지 않습니다.
- 원형봉은 완전한 실원형이고, 원형관은 외경과 내경이 동심이며 두께가 둘레 전체에서 일정하다고 가정합니다.
- 사각형은 완전한 직사각형 실단면입니다. 사각형관은 안쪽 빈 공간이 바깥 단면 중앙에 있고 네 벽 두께가 모두 `t`로 일정하다고 가정합니다.
- H형강은 위·아래 플랜지가 동일하고 웨브가 중앙에 놓인 대칭 단면으로 가정합니다. 플랜지와 웨브를 겹치지 않는 세 직사각형으로 계산하며, 플랜지-웨브 접합부 필릿은 포함하지 않습니다.
- 계산 응력은 각 시점의 하중을 전체 단면적으로 나눈 평균 축응력입니다. 응력 집중이나 굽힘 등은 계산하지 않습니다.

## 분석 및 결과 갱신

1. **CSV 찾아보기**로 파일을 선택합니다.
2. 단면 종류를 선택하고 표시된 치수를 입력합니다.
3. **분석**을 누르면 단면적, 유효 데이터 수, 최대 응력 및 해당 시간과 시간-응력 그래프를 갱신합니다.

새 CSV를 선택하거나 단면 종류 또는 치수를 변경하면 기존 단면적·응력 결과와 그래프를 지우고 `조건변경됨: 다시 분석필요`를 표시합니다. 조건을 변경한 뒤에는 **분석**을 다시 눌러야 새 조건으로 결과가 표시됩니다. 파일 선택 창에서 취소하면 현재 선택 및 결과는 유지됩니다.

## 오류 처리 규칙

- 필요한 치수가 비어 있거나 숫자가 아니면 해당 치수를 입력하라는 안내를 표시합니다.
- 치수에 무한대 등 유한하지 않은 값, 0 또는 음수를 입력하면 오류 이유를 표시하고 분석을 중단합니다.
- 원형관은 `D − 2t > 0`, 사각형관은 `B − 2t > 0` 및 `H − 2t > 0`이어야 합니다. 내부 공간이 없으면 이유와 관련 치수를 안내하고 분석을 중단합니다.
- H형강은 `H − 2tf > 0`, `tw ≤ B`이어야 합니다. 조건을 만족하지 않으면 안내 후 분석을 중단합니다.
- CSV를 읽을 수 없거나 구문이 잘못된 경우, 필수 열 `time_s` 또는 `force_N`이 없으면 오류를 표시합니다.
- 숫자가 아니거나 유한하지 않은 시간·하중이 포함된 행은 제외하고 나머지 유효 행으로 분석합니다. 유효 행이 하나도 없으면 결과와 그래프를 비우고 안내를 표시합니다.
- 분석을 시작할 때 기존 표시 결과를 먼저 지웁니다. 분석 도중 오류가 발생해도 이전 결과가 새 조건의 결과처럼 남지 않습니다.
