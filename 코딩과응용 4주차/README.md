# 힘 단위 변환기

## 프로그램 용도

Tkinter 그래픽 화면에서 힘의 값을 입력하고 단위를 선택하면 N(뉴턴), kN(킬로뉴턴), kgf(킬로그램힘) 값으로 변환합니다. 큰 값은 지수 형식으로 표시합니다. 변환 기록을 확인할 수 있으며, 기록은 프로그램 실행 중 메모리에 보관됩니다.

## 실행 명령

터미널에서 이 파일이 있는 폴더로 이동한 뒤 실행합니다.

```powershell
python force_converterGUI.py
```

Python 실행 명령을 `python`으로 사용할 수 있어야 하며, 실행하면 변환기 창이 열립니다.

## 필요한 환경

- Python이 설치되어 있어야 합니다.
- Python에서 Tkinter를 사용할 수 있어야 합니다. 이 프로그램은 화면을 띄우므로 GUI를 사용할 수 있는 환경이 필요합니다.
- 외부 Python 패키지는 사용하지 않습니다. `math`와 `tkinter`는 코드에서 사용하는 Python 표준 라이브러리입니다.
- 소스 코드만으로 최소 지원 Python 버전이나 각 컴퓨터의 Tkinter 설치 상태는 확인할 수 없습니다.

## 입력 예시

단위를 `kN`으로 선택하고 `2`를 입력한 뒤 **변환**을 누르면 다음 값이 표시됩니다.

```text
N: 2,000.00 N
kN: 2.00 kN
kgf: 203.94 kgf
```

`-1.5`, `0`, `3.25`처럼 Python의 `float`로 변환할 수 있는 유한한 숫자를 입력할 수 있습니다. 음수와 소수도 처리합니다. 숫자 입력 버튼 외에 입력 칸에 직접 입력하거나 Enter 키로 변환할 수도 있습니다.

## 오류 입력 예시

아래 입력은 변환되지 않고 **입력 오류** 경고가 표시됩니다.

| 입력 | 이유 |
| --- | --- |
| 빈 칸 | 입력값이 없음 |
| `abc` | 숫자로 변환할 수 없음 |
| `nan` | 유한한 숫자가 아님 |
| `inf` | 유한한 숫자가 아님 |

오류가 나면 입력 칸에 값을 고친 뒤 다시 변환하면 됩니다.

# CSV 하중·응력 분석기

## 프로그램 용도

`load_data.csv`의 시간과 하중 데이터를 읽어 응력을 계산하고, 응력 그래프와 결과 CSV 파일을 생성합니다. 그래프에는 각 응력 데이터 점을 검은색으로 표시하고 최대응력점에 `MAX-STRESS`와 값을 표시합니다. 실행 중 최대 하중·응력 정보와 응력이 6 MPa를 초과하는 데이터 개수도 출력합니다.

## 입력 파일, 열 및 단위

프로그램 파일과 같은 폴더에 `load_data.csv`를 둡니다. 첫 번째 행은 열 이름이어야 하며 다음 열이 필요합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s(초) |
| `force_N` | 하중 | N(뉴턴) |

열의 순서는 상관없지만 열 이름은 정확히 일치해야 합니다.

## 단면적 설정 및 응력 계산

`load_analyzer.py`의 `AREA_MM2` 값을 시편 단면적(mm²)에 맞게 설정합니다. 현재 설정값은 `100` mm²입니다. 응력은 다음과 같이 계산됩니다.

```text
stress.MPa = force_N / AREA_MM2
```

N/mm²는 MPa와 같으므로 계산 결과 단위는 MPa입니다.

## 필요한 환경 및 라이브러리

- Python이 설치되어 있어야 합니다.
- `pandas`, `numpy`, `matplotlib` 패키지가 필요합니다.
- `pathlib`는 Python 표준 라이브러리입니다.

## 실행 명령

터미널에서 프로그램이 있는 폴더로 이동한 뒤 실행합니다.

```powershell
python load_analyzer.py
```

## 출력 파일 및 결과

성공적으로 분석되면 프로그램 파일과 같은 폴더에 다음 파일이 생성됩니다.

- `load_result.csv`: 유효한 입력 행과 계산된 `stress.MPa` 열
- `Stress_plot.png`: 시간에 따른 응력 그래프와 최대응력 표시

터미널에는 제외 행 수, 유효 데이터 수, 6 MPa 초과 응력 데이터 개수, 최대 하중 및 최대응력과 해당 시간, 그래프 저장 파일명이 출력됩니다.

## 오류 처리 규칙

- 입력 CSV에 `time_s` 또는 `force_N` 열이 없으면 `ValueError`가 발생하고 분석이 중단됩니다.
- 각 행의 시간 또는 하중이 숫자가 아니거나 유한한 값이 아니면 해당 항목과 원본 CSV 행 번호를 출력하고 그 행을 분석에서 제외합니다. 빈 값도 제외 대상입니다.
- 유효한 행이 하나도 없으면 안내 메시지를 출력하고 결과 CSV 및 그래프 생성을 중단합니다.
- `load_data.csv`를 읽을 수 없는 경우(예: 파일이 없거나 CSV를 읽을 수 없는 경우)에는 읽기 오류가 발생합니다.
