# 8주차 풍속 예측

ASOS 108 관측자료를 이용해 시간별 풍속 예측용 데이터셋을 만들고, 선형회귀와 현재 풍속 유지 기준을 비교한 작업입니다. 모든 시각은 KST 기준입니다.

## 파일

- `asos_108_2023_2024.csv`: 원본 관측자료
- `make_wind_dataset.py`: 원본을 시간별로 재정렬하고 입력·정답 데이터셋을 생성하는 스크립트
- `wind_dataset.csv`: 현재 풍속·기온·습도, 1·2시간 전 풍속을 입력으로 구성한 데이터셋
- `train_wind_model.py`: 선형회귀 학습과 2024년 12월 평가를 수행하는 스크립트
- `predictions.csv`: 2024년 12월 평가 결과
- `plot_prediction_week.py`: 2024년 12월 1~7일 예측 그래프를 만드는 스크립트
- `prediction_week.png`: 주간 관측값·기준 예측·선형회귀 예측 그래프

## 데이터셋 생성

원본의 전체 시각 범위에 대해 1시간 간격을 만들고, 빠진 시각은 빈 행으로 취급합니다. 다음 값이 하나라도 없으면 해당 학습 행을 저장하지 않습니다.

- 현재 풍속
- 현재 기온
- 현재 습도
- 1시간 전 풍속
- 2시간 전 풍속
- 1시간 뒤 실제 풍속 정답

```powershell
python make_wind_dataset.py
```

시간 격자 행 수는 `17,544행`, 저장된 데이터셋은 `17,464행`입니다.

## 학습 및 평가

입력은 다음 5개입니다.

1. 현재 풍속
2. 1시간 전 풍속
3. 2시간 전 풍속
4. 현재 기온
5. 현재 습도

정답시각이 2023년 1월부터 2024년 11월까지인 행으로 선형회귀를 한 번 학습하고, 정답시각이 2024년 12월인 행으로 평가합니다. 평가 중에는 모델을 다시 학습하지 않습니다. 회귀 예측이 음수이면 `0`으로 보정합니다.

```powershell
python train_wind_model.py
```

- 학습 행 수: `16,720행`
- 평가 행 수: `744행`
- 현재 풍속 유지 MAE: `0.6534946237 m/s`
- 선형회귀 MAE: `0.5945766854 m/s`

## 그래프

```powershell
python plot_prediction_week.py
```

`prediction_week.png`는 2024년 12월 1일 00시부터 12월 7일 23시까지를 표시합니다.

- 검정색: `Observed`
- 회색 점선: `Current wind baseline`
- 파란색: `Linear regression`

12월 전체 MAE는 기준 예측 `0.6534946237 m/s`, 선형회귀 `0.5945766854 m/s`입니다.
