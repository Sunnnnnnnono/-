# 코딩과 응용 12주차 과제

2023년과 2024년 기상 관측 자료를 이용해 다음 1시간 뒤의 풍속이 강풍 기준인
`4.0 m/s` 이상인지 분류하는 로지스틱 회귀 과제입니다.

## 과제 목표

- 시간별 풍속 자료를 강풍 여부로 표준화하고 이진 분류를 수행합니다.
- 학습 데이터와 평가 데이터를 분리해 모델의 예측 성능을 비교합니다.
- 2024년 12월 강풍 판정 결과를 그래프와 CSV로 저장합니다.

## 데이터 및 처리 기간

| 구분 | 기간 | 데이터 수 |
|---|---|---:|
| 전체 원본 자료 | 2023년 1월 1일 ~ 2024년 12월 31일 | 17,464행 |
| 학습 데이터 | 2023년 1월 1일 ~ 2024년 11월 30일 | 16,720행 |
| 평가 데이터 | 2024년 12월 1일 ~ 12월 31일 | 744행 |

- 강풍 기준: 다음 1시간 풍속이 `4.0 m/s` 이상이면 `label=1`, 미만이면 `label=0`
- 예측 시각과 정답 시각의 차이는 정확히 1시간인지 검증합니다.

## 사용 모델과 비교 방법

현재 풍속과 기온, 습도, 1시간 전 풍속, 2시간 전 풍속을 입력 변수로 사용해
로지스틱 회귀 분류기를 학습합니다.

평가에서는 다음 네 가지 방법을 비교합니다.

| 방법 | 설명 |
|---|---|
| `always_zero` | 모든 시각을 비강풍으로 판정 |
| `current_wind_4plus` | 현재 풍속이 4.0 m/s 이상이면 강풍으로 판정 |
| `logistic_050` | 로지스틱 회귀 확률이 0.50 이상이면 강풍으로 판정 |
| `logistic_020` | 로지스틱 회귀 확률이 0.20 이상이면 강풍으로 판정 |

평가 지표는 정확도, 정밀도, 재현율과 혼동행렬을 구성하는 적중, 오탐,
미탐, 정상 판정 수로 계산합니다.

## 파일 설명

| 파일 | 설명 |
|---|---|
| `classify_wind.py` | 데이터 표준화, 로지스틱 회귀 학습, 예측, 점수 계산 및 그래프 생성 |
| `wind_dataset.csv` | 학습과 평가에 사용하는 원본 시계열 자료 |
| `wind_dataset_labeled.csv` | 풍속 기준에 따라 `label` 열을 추가한 전체 자료 |
| `classification_predictions.csv` | 2024년 12월 744개 시각의 실제값과 예측값 |
| `classification_scores.csv` | 네 가지 판정 방법의 평가 지표 |
| `strong_wind_december.png` | 2024년 12월 1~7일의 풍속과 강풍 판정 비교 그래프 |

## 실행 방법

```bash
pip install matplotlib
python classify_wind.py
```

실행 위치와 관계없이 스크립트가 위치한 폴더를 기준으로 입력과 출력
파일을 처리합니다.

## 실행 결과

평가 기간에는 실제 강풍 39건이 포함되어 있습니다.

| 방법 | 정확도 | 정밀도 | 재현율 | 적중 | 미탐 | 오탐 |
|---|---:|---:|---:|---:|---:|---:|
| always_zero | 0.947581 | 해당없음 | 0.000000 | 0 | 39 | 0 |
| current_wind_4plus | 0.919355 | 0.230769 | 0.230769 | 9 | 30 | 30 |
| logistic_050 | 0.943548 | 0.333333 | 0.076923 | 3 | 36 | 6 |
| logistic_020 | 0.912634 | 0.267857 | 0.384615 | 15 | 24 | 41 |

강풍 판정을 위한 임계값을 낮추면 미탐은 줄어들지만 오탐이 증가하는 것을
확인할 수 있습니다.
